# 常见问题

## 装完之后打不开，或提示需要激活

安装不等于授权。本工具只负责把 Office 装到电脑上，不提供任何激活手段。

合法激活方式：

- **Microsoft 365 订阅**：打开 Word，右上角登录已购买订阅的账号，登录后自动激活
- **零售永久版**（Office 2021 / 2024 家庭版等）：按提示输入 25 位产品密钥
- **学校或公司账号**：用组织分配的账号登录即可
- 只是临时看文档：`office.com` 网页版免费，不用装桌面版

如果产品版本和你的授权不匹配（例如买了家庭版却装了企业版），登录后仍然激活不了。本工具的产品下拉里可以切换版本重装，选与授权对应的那一项。

## 双击 exe 提示"Windows 已保护你的电脑"

exe 没有购买代码签名证书。点「更多信息」→「仍要运行」即可。

不放心的话可以按 README 里的说明自己编译：只需要 Windows 自带的 PowerShell，执行 `build.ps1` 就能得到同样的 exe。

## 杀毒软件报毒

和上一条同源：未签名程序 + 会调用 `setup.exe` 安装软件 + 会下载大文件，这几个特征容易触发启发式告警。程序本身不联网上传任何数据，只访问微软官方 CDN（`officecdn.microsoft.com`）和微软下载页。

## 下载很慢，或者下到一半断了

- 下载支持断点续传，直接重新点「开始安装」会接着上次的进度，不会从头来
- 镜像完整性按服务器返回的文件大小判断，不完整会自动续传
- 走代理的话，`officecdn.microsoft.com` 建议加进直连规则，国内直连通常更快

## 提示"未找到 OSPP.VBS"

部分 Office 安装包不包含这个脚本（订阅版镜像里可能没有）。它只用来查询和配置授权状态，缺失不影响 Office 正常使用和激活。

可行的补救方式：设置 → 应用 → Microsoft 365 → 修改 → 快速修复，会补回缺失文件。

## 安装失败了，怎么看原因

界面右下角会显示返回码，同时把日志目录打开：

```
%TEMP%\O365_Setup\logs
```

Office 自己的日志在 `%TEMP%` 下，文件名形如 `计算机名-日期-时间.log`。常见返回码：

- `17004`：与另一个 Office 安装/卸载操作冲突，等几分钟再试
- `1603`：产品 ID 或更新通道不被接受
- `30182-...`：网络中断或源文件损坏

## 电脑上已经有 Office 了，会不会冲突

安装流程**不会**动你已有的 Office。如果确实要卸载旧版，主界面左下角有「卸载旧版」按钮，可以分别处理即点即用版和 MSI 版。

注意：卸载 MSI 版 Office 时若勾选了与当前版本共用组件的条目，`OSPP.VBS` 会被一起删掉，不影响 Word/Excel 使用，但授权状态查不了。

## 能离线装到多台电脑吗

可以。安装时勾选「完成后保留安装源」，镜像会留在：

```
%TEMP%\O365_Setup\
```

拷到其他电脑的同一位置，程序检测到完整镜像会跳过下载直接安装。

ODT 在线模式下保留下载目录（`source`），删掉缓存意味着要重新下几个 G。

## 支持哪些版本

Microsoft 365（企业应用版 / 商业版 / 家庭版）、Office 2024 / 2021 / 2019（零售与 LTSC 批量）、Visio、Project、单独应用。

Office 2016 属于实验性支持，且没有官方离线镜像，只能在线下载安装。2016 和 2019 均已结束支持，不再有安全更新，仅建议用于兼容旧插件等场景。

## 卸载 Office

用主界面「卸载旧版」，或者系统设置 → 应用 → 找到 Microsoft 365 → 卸载。两者等价。

## 这个工具会收集我的信息吗

不会。程序不联网上报任何数据，网络请求只有两类：拉取微软官方安装文件、下载 Office 部署工具。
